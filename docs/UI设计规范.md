## 1. 设计语言

- **风格**：**数据密集型仪表盘（Data-Dense Dashboard）**。多图表 / KPI 卡 / 数据表，紧凑网格布局，空间高效，最大化数据可见性。
- **气质**：专业、可信赖、技术精确——这是面向研发与运维的基础设施控制台，不做花哨装饰。
- **三条原则**：
  1. **信息密度优先**：紧凑但不拥挤，用留白分组而非堆砌色彩。
  2. **状态一目了然**：模型 / Key / Provider 的健康、启停、熔断状态用语义色 + 文字双重表达（不靠颜色单独传达）。
  3. **可读数字**：所有数据列、价格、Token 用**等宽数字**（tabular-nums）防止跳动。
- **避免**（反模式）：过度装饰、拟物阴影、无筛选的大表格、emoji 当图标。

> 用 CSS 变量 + Tailwind 主题；语义化命名，组件内不写裸 hex。光/暗双套独立校准对比度（≥ 4.5:1 正文）。

### 2.3 语义状态色（徽标 Badge）

| 状态 | 色 | 适用 |
|------|----|------|
| 健康 / 启用 / 成功 | 绿 `#16A34A` | Provider 健康、Key 启用、请求成功 |

## 3. 排版

- **标题 / 品牌 / KPI 标签**：**Fira Code**（等宽，技术精确感）。
- **正文 / 表格 / 表单**：**Fira Sans**。
- **数字 / ID / Key / 代码块**：**Fira Code**（tabular-nums），用于价格、Token、request_id、`sk-...`。

```css
@import url('https://fonts.googleapis.com/css2?family=Fira+Code:wght@400;500;600;700&family=Fira+Sans:wght@300;400;500;600;700&display=swap');
```

- **字阶**：12 / 14 / 16 / 18 / 24 / 32（正文基准 14，后台可比 16 略紧）。
- **行高**：正文 1.5；表格 1.4。
- **字重**：标题 600–700、标签 500、正文 400。
- `font-display: swap` 防 FOIT。

## 4. 布局骨架

经典「侧边栏 + 顶栏 + 内容」后台壳（AdminLayout）：

```
┌────────────┬─────────────────────────────────────────────────┐
│            │  顶栏: 面包屑           🔍搜索  🌗主题  👤用户 ▼   │
│  LOGO      ├─────────────────────────────────────────────────┤
│  simple-ai │                                                   │
│ ┌────────┐ │   ┌─KPI─┐ ┌─KPI─┐ ┌─KPI─┐ ┌─KPI─┐                │
│ │概览     │ │   │请求 │ │Token│ │费用 │ │延迟 │                │
│ ├────────┤ │   └─────┘ └─────┘ └─────┘ └─────┘                │
│ │AI 治理 ▾│ │   ┌──────────────────┐ ┌──────────────┐          │
│ │ 模型    │ │   │  用量趋势 (折线)   │ │ 模型排行(条形)│          │
│ │ 别名路由│ │   └──────────────────┘ └──────────────┘          │
│ │ 价格    │ │   ┌─────────────────────────────────────┐        │
│ ├────────┤ │   │  数据表（分页/筛选/排序）              │        │
│ │应用密钥▾│ │   └─────────────────────────────────────┘        │
│ │计费统计▾│ │                                                   │
│ │系统    ▾│ │                                                   │
│ └────────┘ │                                                   │
└────────────┴─────────────────────────────────────────────────┘
```

- **侧边栏**：桌面固定 240px，可折叠 64px（仅图标）；分组导航 + 当前项高亮（左侧条 + 主色）；图标用 **Lucide**。
- **顶栏**：面包屑（3 级以上必有）、主题切换、用户菜单；危险操作（登出）与普通项视觉分离。
- **响应式**：≥1024px 用侧边栏；<1024px 收为抽屉（Sheet）。导航位置全站一致。
- **间距**：4/8px 节奏体系；内容区栅格 12 列，gutter 16–24px；卡片内边距 16–24px。
- **z-index 分层**：0 / 10(粘性头) / 20(下拉) / 40(抽屉) / 50(弹窗) / 60(toast)。

## 5. 组件规范（shadcn/ui，目标；当前落地以 `web/` 为准）

| 组件 | 规范 |
|------|------|
| **Button** | 每屏仅一个主 CTA（primary）；次级用 outline/ghost；异步操作 `disabled + Loader2 spinner`；危险操作用 destructive 色并与主操作分离 |
| **Table（DataTable）** | TanStack Table；表头 muted、斑马纹、行悬停高亮；**列支持排序（aria-sort）+ 筛选 + 分页**；多选 + 批量操作栏；数字列右对齐 + tabular-nums；移动端 `overflow-x-auto` 或卡片化 |
| **Form** | react-hook-form + zod；**可见 label**（非仅 placeholder）；错误显示在字段下方；必填星标；blur 时校验；提交后聚焦首个错误字段 |
| **Card / KPI** | KPI 卡：大号 tabular 数字 + 标签 + 环比小箭头（↑绿/↓红，含文字）+ 迷你趋势线 |
| **Badge** | 状态徽标按 §2.3，圆点+文字 |
| **Dialog / Sheet** | 弹窗用于确认与表单；删除等破坏性操作二次确认；遮罩 40–60% 黑；有未保存内容时关闭前确认 |
| **Toast（Sonner）** | 3–5s 自动消失；`aria-live=polite` 不抢焦点；操作成功/失败反馈 |
| **Skeleton** | 加载 >300ms 用骨架屏，不要空白冻结 |
| **Empty State** | 无数据时给文案 + 操作指引，不显示空图表/空表 |

## 6. Dashboard 与图表指南（Recharts）

| 指标 | 图表 | 要点 |
|------|------|------|
| 请求量 / Token / 费用 **随时间** | **折线图 / 面积图** | 有时间轴看趋势；多序列用不同颜色**+不同线型**（实/虚/点，色盲友好）；填充 20% 透明；>1000 点降采样 |
| 模型 / 部门 / 应用 **排行对比** | **条形图（横向，降序）** | 类别 ≤15；每条带数值标签；提供 CSV 导出 |
| 配额 / 预算 **使用率 vs 上限** | **Bullet / Gauge / Progress** | 数值 + % 以文字常显（非仅 hover）；阈值区间用文字标注 |
| KPI 汇总 | **统计卡（Stat Card）** | tabular 数字 + 环比 |
| 状态分布（≤5 类） | **环形图 Donut** | 超过 5 类改条形 |

**图表通用规范**：
- 始终显示**图例**（靠近图表）、**hover/tap tooltip**（精确值）、**坐标轴单位**。
- 网格线低对比（slate-200 / 暗色 slate-700），不与数据争夺注意力。
- 图例可点击切换序列显隐；交互元素可键盘到达。
- **空 / 加载 / 错误**三态齐全：加载用骨架、失败给重试、无数据给文案。
- 为屏幕阅读器提供图表要点的文字摘要（aria-label）。
- 图表色板（分类）：`#1E40AF #D97706 #16A34A #DC2626 #7C3AED #0891B2`，配合线型/纹理区分。

## 8. 暗色模式与无障碍

- **暗色**：用降饱和/提亮的色阶，不是简单反色；光暗各自验证对比度；边框/分隔/交互态在两套都可辨。
- **对比**：正文 ≥4.5:1，次要文字 ≥3:1，图标/大字 ≥3:1。
- **焦点**：所有可交互元素可见焦点环（2–4px `--ring`），键盘 Tab 顺序与视觉一致。
- **动效**：150–300ms，仅用 transform/opacity；尊重 `prefers-reduced-motion`。
- **图标**：统一 **Lucide**，一致描边宽度，禁用 emoji；图标按钮配 `aria-label`。
- **点击区**：可点元素 `cursor-pointer`；小图标按钮扩展热区。

## 附：落地建议

- 用 shadcn 初始化时把 §2 的 token 写入 `globals.css` 的 `:root` / `.dark` 与 `tailwind.config` 主题，后续组件只引用语义变量。
- 图表统一封装 `<ChartCard>`（含标题/工具栏/空-加载-错三态），各页复用。
- 状态徽标封装 `<StatusBadge status="healthy|degraded|down|cooldown|disabled" />`，全站一致。
- 可参考 shadcn/ui 官方示例与同类开源网关的 Dashboard / 日志 / 价格表页面布局。
